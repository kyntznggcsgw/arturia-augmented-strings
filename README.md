## Overview

Arturia Augmented Strings blends acoustic string ensemble samples with synthesis engines, creating sounds that span from realistic orchestral textures to evolving hybrid soundscapes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Arturia Augmented Strings** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Acoustic Samples** | High-quality string ensemble and solo string recordings |
| **Synthesis Layer** | Wavetable and FM synthesis layered with acoustic samples |
| **Blend Knob** | Single knob morphs between acoustic and synthetic character |
| **FX Chain** | Built-in effects including reverb, chorus, and EQ per layer |
